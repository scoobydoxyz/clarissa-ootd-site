Clarissa ootd

Turn product photos into TikTok videos and save them to your drafts for review before posting.

Clarissa ootd is a creator tool. It takes a product photo, edits it following a saved reference style and prompt, turns it into a short video, and uploads that video to the creator’s own TikTok drafts using the TikTok Content Posting API. Nothing is published automatically: the creator reviews each draft in the TikTok app before posting.

The app uses TikTok Login Kit to connect the creator’s own TikTok account, and the Content Posting API (video.upload scope) to upload videos to that account’s inbox as drafts.
